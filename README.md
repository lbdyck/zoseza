# zoseza
a python vibe coded clone of eza

See https://eza.rocks/ or https://github.com/eza-community/eza for a real executable.

This clone was created because there is no executable for z/OS and no way to port it to z/OS at this time.

```
usage: zoseza.py [-h] [-a] [-l] [-g] [-t] [-i] [-b] [-J FILE] [-e EXT] [-R PATTERN] [-T] [-x] [--tree] [-d] [-S] [-r] [-1] [-D] [--tui]
                 [paths ...]

Python eza clone for z/OS

positional arguments:
  paths

options:
  -h, --help           show this help message and exit
  -a, --all
  -l, --long
  -g, --git
  -t, --time
  -i, --icons
  -b, --blocks
  -J, --json FILE
  -e, --ext EXT
  -R, --regex PATTERN
  -T, --tags
  -x, --extattr
  --tree
  -d, --directory
  -S, --sort-size
  -r, --reverse
  -1, --oneline
  -D, --dsn
  --tui

```

Google Gemini was used for this project
